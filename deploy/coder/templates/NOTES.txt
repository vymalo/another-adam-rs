{{- if gt (int .Values.replicaCount) 1 }}

Scaling down deletes every removed worker at once (`podManagementPolicy: Parallel`). A per-pod volume stays, and the
runs that worker owned are stranded: only a shared placement (`workspace.placement: shared` or `affinity`) keeps them
reachable from another worker.
{{- end }}

{{- $modelAuth := include "coder.modelAuth" . -}}
{{- if and (has $modelAuth (list "device" "injector")) .Values.externalSecrets.enabled (include "coder.runsWorkers" .) }}

Model auth: {{ $modelAuth }} (MODEL_AUTH). With `device` or `injector` the coder holds no model key.
{{- if eq $modelAuth "injector" }}
Every call carries X-Run-Id and no Authorization, and an injector in front of the model adds the run's
credential (ADR 0067).
{{- else }}
It signs in to MODEL_OAUTH_ISSUER with the device grant (ADR 0058).
{{- end }}
The ExternalSecret still copies MODEL_API_KEY from externalSecrets.properties.modelApiKey
({{ .Values.externalSecrets.properties.modelApiKey }}), and that property's value must be EMPTY: the coder
refuses to start with a non-empty key under `device` or `injector` (exit 78). The chart cannot read the value.
{{- end }}
{{- if and (eq $modelAuth "injector") (include "coder.runsWorkers" .) (not (include "coder.modelBaseUrlFromSecret" .)) (not (include "coder.modelBaseUrlLiteral" .)) }}

WARNING: config.modelAuth is injector and config.modelBaseUrl names no real gateway (it is still the
placeholder, {{ include "coder.modelBaseUrlPlaceholder" . }}, or empty). Every model call would go there,
and every run would park for up to MODEL_PARK_LIMIT (ADR 0067). Point config.modelBaseUrl at the injector
(or set config.modelBaseUrlFromSecret).
{{- end }}

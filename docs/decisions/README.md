# Decisions

Each decision is an ADR: a short record of the context, the decision and its consequences, named
`NNNN-kebab-title.md`. ADRs are history: a change to a past decision is a dated *Amended* note in the ADR, never a
silent edit, and a decision that replaces another says so in both. *Proposed* means the owner has yet to confirm it.

# Contributing

The front door is [`CONTRIBUTING.md`](../CONTRIBUTING.md) at the repository root: how to claim an issue, build, test and
open a pull request. Security reports go through [`SECURITY.md`](../SECURITY.md), never a public issue. Where the library
is going is the [roadmap](roadmap.md).

Coding agents work from [`CLAUDE.md`](../CLAUDE.md) and [`.agents/docs/`](../.agents/docs/README.md); a page here that has
a counterpart there links to it ([ADR 0079](decisions/0079-docs-for-people-and-docs-for-agents-live-apart.md)).

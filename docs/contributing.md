# Contributing

Start with [`CONTRIBUTING.md`](https://github.com/vymalo/another-adam-rs/blob/main/CONTRIBUTING.md): how to claim an
issue, build, test and open a pull request. It stays at the repository root and is linked from here, not copied, so
there is one version to keep true. Where the library is going is the [roadmap](roadmap.md).

| I want to... | Go to |
|---|---|
| Build and test | [Set up, build and test](https://github.com/vymalo/another-adam-rs/blob/main/CONTRIBUTING.md#set-up-build-and-test), then [Testing](guides/testing.md) for every suite and script |
| Run the coder on my machine, with no credential | [Run it locally](guides/run-locally.md) |
| Write or change docs | [Writing docs](writing-docs.md) |
| Open a pull request | [Open a pull request](https://github.com/vymalo/another-adam-rs/blob/main/CONTRIBUTING.md#open-a-pull-request) and the [conventions](https://github.com/vymalo/another-adam-rs/blob/main/CONTRIBUTING.md#conventions) |
| Report a vulnerability | [`SECURITY.md`](https://github.com/vymalo/another-adam-rs/blob/main/SECURITY.md), never a public issue |
| Install the skills this repository provides | [Agent skills](skills.md) |

Coding agents work from [`CLAUDE.md`](https://github.com/vymalo/another-adam-rs/blob/main/CLAUDE.md) and
[`.agents/docs/`](https://github.com/vymalo/another-adam-rs/blob/main/.agents/docs/README.md); a page here that has a
counterpart there links to it ([ADR 0079](decisions/0079-docs-for-people-and-docs-for-agents-live-apart.md)).
